![Python](https://img.shields.io/badge/Python-3776AB?style=flat&logo=python&logoColor=white)
![Tableau](https://img.shields.io/badge/Tableau-E97627?style=flat&logo=tableau&logoColor=white)

![GitHub Actions](https://img.shields.io/badge/GitHub%20Actions-2088FF?style=flat&logo=githubactions&logoColor=white)

An analysis of recorded explosive-weapon incidents affecting civilian services in Ukraine since 24 February 2022.

What started as a Python + Tableau analysis developed into an automated ETL pipeline. The project retrieves the latest data from HDX, cleans and validates it, uploads processed tables to Google Sheets and feeds a Tableau Public dashboard.

The pipeline runs automatically once a week using GitHub Actions.

# What I'm Practicing 🏋🏻

Across these projects I'm focusing on the full analytical process rather than only dashboard creation:

```text
Raw Data
   ↓
Data Cleaning
   ↓
Exploration
   ↓
Data Modelling
   ↓
Metric Definition
   ↓
Validation
   ↓
Analysis
   ↓
Visualization
   ↓
Insights
```

I'm particularly interested in projects where the data is imperfect and requires decisions about structure, definitions and quality before the visualization stage.
